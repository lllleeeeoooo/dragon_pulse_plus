这份 dragon_pulse_plus
监控与风控规则文档整体架构非常清晰，涵盖了盘前、竞价、盘中、尾盘、盘后以及看门狗等完整的闭环，且具备降级机制（LLM失败回退规则）。

但站在 A股超短/打板/情绪博弈实战 以及 量化系统设计 的角度仔细研读后，可以发现文档中存在多处逻辑漏洞、回测未来函数（Look-ahead
Bias）、不符合实盘微观结构、以及数值/公式设置不合理的地方。

以下是为你梳理出的四大类核心问题及具体修改建议：

一、 严重逻辑硬伤与未来函数（会导致回测失真或实盘亏损）

1. 尾盘博弈 (AI_TAIL) 次日兑现存在“未来函数” (致命)

  - 规则描述：“开盘 ≥ 成本×(1 + 2%) 视为高开，在开盘价~当日最高之间按 TAIL_GAME_TAKE_RATIO=0.5 比例兑现”
  - 不合理点：在次日 09:30-10:30 执行卖出决策时，系统根本不可能提前知道“当日最高价 (High)”是多少！
      - 如果这是回测逻辑，使用了全天 High，属于典型的未来函数，会导致回测收益严重虚高。
      - 如果这是实盘逻辑，无法挂单执行（交易所不支持挂“开盘价与最高价中点”的订单）。
  - 建议修改：实盘/回测必须基于实时挂单机制。例如：
      - 策略 A：09:30 开盘直接按市价单兑现；
      - 策略 B：冲高止盈，监测 9:30-10:00 动态分时，若相对开盘拉升 >X% 且出现分时回落 Y% 则市价落袋，10:30 无条件市价清仓。

2. 时间止损 (TIME_STOP_LOSS_DAYS) 错用“自然日” (逻辑漏洞)

  - 规则描述：“按自然日 (now - buy_date) 而非交易日计算，跨周末/节假日会更快触发。”
  - 不合理点：A股是 T+1 且周末/节假日不交易。周五买入的股票，周一开盘时 now - buy_date 已经到了第 3
    天（自然日），周一早盘就会直接误触发时间止损！这会导致周五买入的股票在周一被无脑抛售。
  - 建议修改：必须严格改为交易日 (Trading Days) 计算。

3. 强止盈 (CRITICAL) 缺少“高点回落”判定，会砍掉主升浪超级龙头

  - 文档自述：“TAKE_PROFIT_CRITICAL_PCT 的注释声称‘且从高点回落’才触发，但实际代码未实现高点回落判断——纯按
    profit_pct >= 20% 触发。”
  - 不合理点：超短策略核心盈利来自于妖股/主升浪连板（如 3-5 连板收益轻松超 30%）。若盈利达到 20%
    仅因“到达数值”就强行平仓，会截断利润，导致策略“吃小亏、漏大赚”，盈亏比严重恶化。
  - 建议修改：必须补齐高点回落逻辑！例如：profit_pct >= 20% 且 (最高价 - 现价) / 最高价
    >= 5%（最高点回落 5%）才执行强平止盈。

4. 卖出 LLM 冷却时间 (1800s) 存在风控盲区

  - 规则描述：“LLM 判‘持有’→ 不卖，并进入 1800 秒（30分钟）冷却，冷却期内不重复咨询”
  - 不合理点：A股情绪退潮或闪崩往往发生在 1-3 分钟内。若 LLM 刚判了“持有”，2 分钟后股票从 +5% 瀑布水下 -5%，由于处于 1800s
    冷却期内，LLM 将无法参与救场，导致硬生生砸穿止损线。
  - 建议修改：增加破局解冻条件——若冷却期内股价出现急跌（例如 3 分钟内回落幅度 > 3% 或 跌破 VWAP 分时均线），强行打破 1800s
    冷却，立即重新触发 LLM 或直接执行规则卖出。

二、 公式与微观结构设置不合理

1. “低开猛拉”拉升强度公式易被异常单刷爆

  - 公式描述：\text{拉升强度} = \frac{\text{现价} - \text{开盘}}{\text{最高} - \text{最低}}
  - 不合理点：开盘前几秒（如 09:30:15），如果最高价等于现价，最低价等于开盘价，分母分子相等，强度直接为
    1.0。早盘单笔数百手拉高就会瞬间触发该信号，极易诱发虚假点火。
  - 建议修改：
    1.  分母增加保护项防止分母过小：\frac{\text{现价} - \text{开盘}}{\max(\text{最高} - \text{最低}, \text{昨收} \times 1\%)}；
    2.  强制要求拉升幅度：要求 (\text{现价} - \text{开盘}) / \text{昨收} \ge 2.0\%。

2. 买入滑点模型 (AI_BUY_SLIPPAGE_PCT) 过于乐观

  - 规则描述：“普通滑点 0.3%，逼近封板/高位放量加 0.2% (共 0.5%)”
  - 不合理点：对于超短“逼近封板”（+8%~+9.5% 扫货）策略，在实盘中，打板资金抢筹极快，市价单挤入时往往直接撮合在涨停价 (+10%)，滑点高达
    1%~2%，或者根本买不进去（封死）。0.5% 的滑点假设会导致回测严重失真。
  - 建议修改：对“逼近封板”信号，滑点应设定为 (涨停价 - 当前价)，即假设以涨停价买入；若封单过大，则按买不入处理。

3. 概念门控 (Concept Gate) “一滴水放行”逻辑形同虚设

  - 规则描述：“仅当全部概念均明确负向才否决；存在任一可买概念即放行”
  - 不合理点：A股个股往往挂载 10-20
    个概念标签（包含“边缘概念”如“创投”、“电商”等）。如果某股票主线概念（如“机器人”）已经在严重退潮，但某个边缘概念（如“国企改革”）被判定为“发酵”，该逻辑就会放行！这完全失去了风控的意义。
  - 建议修改：应按概念关联度/权重过滤，或取成交量最大的前 2 个核心概念。只有当核心概念处于可买阶段时才放行。

4. 容量因子 K 早盘预估成交额失真

  - 公式描述：K = \text{今日预估成交额} / \text{20日均成交额}
  - 不合理点：A股全天成交量呈现典型的 U型曲线（09:30-10:00 成交量占全天 30%-40%）。如果在 09:35 简单用 当前成交量 / 5分钟
    * 240分钟 线性外推预估全天成交额，会放大 2-3 倍，导致 K 因子严重偏高，误判市场处于“极度增量状态”。
  - 建议修改：预估全天成交额必须采用 分时累计成交量比例系数 (Intraday Volume Profile Coefficient)
    进行折算，而非线性乘积。

三、 交易频率与性能瓶颈

1. 15 秒主轮询间隔对打板/抢筹过慢

  - 规则描述：MONITOR_INTERVAL_SECONDS = 15
  - 不合理点：A股超短封板往往在 3-5 秒内完成。15 秒轮询 + 数据采集延迟，股票可能已经从 +7%
    瞬间封死涨停，系统才刷出信号，此时已经买不进去了。
  - 建议修改：
      - 将全市场扫描与**重点监控池（已触发预警标的）**解耦；
      - 全市场扫描可保持 10-15s，但针对已命中“点火/逼近封板”的标的，应提升至 1-3秒 高频轮询。

2. LLM 买入确认同步阻塞主循环

  - 规则描述：“每轮最多 1 次同步 LLM 调用（控制 15s 主循环阻塞）”
  - 不合理点：大语言模型 API 响应时间通常在 1.5s - 4s 之间。如果在主线程中同步调用 LLM，不仅会拉长 15s
    轮询周期，还会导致卖出风控（止损）被买入 LLM 响应时间拖累。
  - 建议修改：LLM 评估必须采用 异步任务队列 (Async Worker Queue)。主循环负责抓取行情和触发规则风控，买入/卖出 LLM
    的决策放在后台异步协程中，决不能阻塞主监控循环。

四、 监管红线与竞价门槛

1. 竞价成交额占比阈值（8%~10%）缺少市值归一化

  - 规则描述：“竞价金额占昨日全天成交额 > 8%~10% → 超预期抢筹”
  - 不合理点：
      - 对于 5000 万小成交额的妖股，竞价 400 万（8%）非常常见；
      - 但对于 50 亿巨量成交的中军/大盘股，竞价需要 4 亿-5 亿才能达标，这几乎是不可能的。
  - 建议修改：竞价占比门槛应与市值/昨日成交额分阶梯设置。中大盘股（昨日成交 > 10亿）阈值应下调至 3%~5%。

2. 监管异动 (Yidong) 3日偏离度未与最新交易所规则联动

  - 规则描述：“主板 3日偏离度红线 20%”
  - 提醒：沪深交易所对主板严重异动的判定规则曾多次微调（例如“连续3个交易日内日收盘价格涨跌幅偏离值累计达到±20%”）。更关键的是，偏离度计算中的“基准指数”（如上证综指或深证成指）每日波动需要精准实时扣除，且必须严格对齐交易所官方公布的“异动公告起始日”，否则容易算错 1-2
    个交易日的窗口。

五、 优化总结速查表（建议优先修改项）

| 模块        | 原规则/逻辑        | 存在风险            | 推荐修改方案                           |
| :-------- | :------------ | :-------------- | :------------------------------- |
| **尾盘兑现**  | 依赖次日全天最高价兑现   | 严重未来函数，实盘无法挂单   | 改为 09:30-10:00 动态移动止盈，10:30 强制平仓 |
| **时间止损**  | 按自然日计算        | 跨周末（周五买周一卖）误杀   | **严格改为交易日计算**                    |
| **强止盈**   | 达到 20% 直接平仓   | 砍掉超级大黑马/主升浪龙头   | 增加 **高点回落 5%** 复合触发条件            |
| **卖出LLM** | 判持有后冷却 30 分钟  | 遇到闪崩/急跌时无法及时卖出  | 增加跌破 VWAP 或急跌 3% **打破冷却**机制      |
| **买入滑点**  | 逼近封板给 0.5% 滑点 | 回测严重过于乐观        | 逼近封板按**涨停价撮合**或模拟封板排队失败          |
| **概念门控**  | 任一概念正向即放行     | 边缘概念干扰，风控形同虚设   | 取**前 2 大核心概念**进行阶段门控             |
| **架构执行**  | LLM 在主循环内同步调用 | 阻塞 15 秒主循环，拖慢止损 | 改为 **Async 异步队列** 执行 LLM 交互      |
