 设计一款AI智能策略应用，使用akshare数据，结合bark推送。
核心逻辑架构：基于“情绪周期”的量化
我们将市场分为：冰点期、启动期、发酵期、高潮期、退潮期。
首先要识别当前市场风格，1、市场有宽度无高度，只做低吸。2、市场有高度无宽度，只做打板。3、市场杀跌阶段，紧盯抱团。4、行情上涨阶段，寻找共振。
1. 低吸战法：寻找板块中军回踩
核心逻辑： “中军”通常是大市值、高流动性的领头羊。由于资金介入极深，它们很难像小盘妖股那样直接“A杀”，回踩关键均线（如10日、20日线）时，会有护盘资金或踏空资金进场补票。
适用时机： 主线题材的中期波动。
操作要点：
缩量： 回踩时必须是缩量的，证明没有大机构集体砸盘。
支撑位： 关注整数关口或重要移动平均线。
分时止跌： 看到分时图出现“圆弧底”或不再创出新低时介入。
优点： 容错率高，适合大资金。
2. 打板战法：启动期与发酵期
核心逻辑： 打板是为了确认强度。启动期打板是抢先手，博弈成为龙头的概率；发酵期打板是博弈板块的群体效应（溢价空间）。
适用时机： 题材刚出消息或板块走出连板梯队。
操作要点：
启动期： 关注“首板”或“一进二”，看谁先封板，谁的形态更具美感。
发酵期： 关注“龙一、龙二”，由于已有赚钱效应，打板是为了拿明天的溢价。
风险： 容易遭遇“炸板”或隔日大幅低开。
3. 二波战法：退潮后的修复期
核心逻辑： 一个顶级题材不会一次性死掉。第一波见顶回落后，经过充分换手（一般5-10个交易日），会有资金博弈反抽或政策利好二次兑现。
适用时机： 老龙头腰斩后止跌，或板块指数形成“双底”结构。
操作要点：
核心标的： 只做第一波的人气总龙头，不做跟风盘。
信号： 出现反包大阳线，或者小弟们先开始异动。
难点： 很多二波最后只变成了“山顶的诱多”，如果没创新高，要坚决离场。
4. 抱团战法：存量博弈下的避风港
核心逻辑： 市场没钱了（量能缩到极低），新题材拉不动。资金会收缩战线，躲进流动性最好、逻辑最硬的几只个股里（如红利资产或当时的超级妖股）。
适用时机： 指数震荡阴跌、量能极度萎缩、新题材一日游频繁。
操作要点：
特征： 走势特立独行，不跟随指数大跌，甚至逆势小阴小阳拉升。
死穴： 补跌。一旦指数反弹，新题材启动，抱团股往往会崩坍（资金去流向新题材）。
5. 共振战法：题材与指数齐飞
核心逻辑： 这种战法是确定性最高的。当指数大阳起跳的同时，出现了一个强势的新题材，这意味着全市场达成共识，大级别的行情开启。
适用时机： 冰点期后的放量大阳。
操作要点：
首板接力： 寻找在指数大涨当天，最先封板且带板块效应的个股（即“共振龙”）。
仓位： 这种时刻应该重仓，博弈初期的连板溢价。
价值： 这就是常说的“买在分歧，卖在一致”。


系统难点：
“中军”与“板块”的动态关联（难点）：
硬编码无法定义谁是中军。今天AI的中军可能是浪潮信息，明天可能变成工业富联。板块的构成也是动态的（同花顺概念经常变动）。
情绪周期的模糊边界（难点）：
“发酵期”和“高潮期”的界限在哪里？单纯靠涨停家数容易误判（比如指数大跌时的避险涨停）。
异动逻辑的归因（缺失）：
盘中某只股突然点火，是“共振战法”的信号，还是“二波战法”的脉冲？单纯的价格/成交量监控无法分辨逻辑背景。
复盘的“神韵”（缺失）：
复盘不只是看数字，更要看“龙虎榜”背后游资的风格（是格局派还是砸盘王）。
以下是针对这四个痛点的具体进阶方案：

1. 完善“中军”与“板块”的动态关联
痛点： 核心标的在变，板块联动复杂。
完善方案：【动态市值权重+相关性分析】
数据逻辑（Python）：
动态权重： 每日盘后，自动计算所属板块内“成交额前3”且“总市值前5”的个股。
相关性分析（Beta）： 计算个股走势与所属行业指数的皮尔逊相关系数（Correlation）。系数 > 0.8 且成交额大于 20 亿的，自动标记为“临时中军”。
LLM 介入：
概念提取： 每天调用 ak.stock_board_industry_cons_em 获取成分股，让 AI 分析近期研报高频词。
身份定义： AI 识别谁是“逻辑锚点”（如：工业富联代表算力硬件，宁德时代代表赛道强度）。
实现： 建立一个Active_Core_Pool（动态核心池），每天盘前根据成交额更新，解决硬编码问题。

2. 完善“情绪周期”的模糊边界
痛点： 涨停数不能完全代表周期，容易误判。
完善方案：【情绪多维向量评分系统】
不要只看涨停数，要构建一个 “情绪指数 (Sentiment Index)”，由五个维度加权：
高度（Height）： 市场最高连板天数。
宽度（Breadth）： 涨停家数 - 跌停家数。
反馈（Yield）： 昨日涨停个股今日的平均开盘溢价（最重要：决定了赚钱效应的延续性）。
力度（Force）： 封单金额占市场总成交额比例。
承接（Support）： 炸板率（炸板数 / 总封板数）。
LLM 任务：
输入这5个维度的数据。
判断逻辑： 如果“高度”在降但“宽度”在增，AI 判断为“高低切换”；如果“高度”和“溢价”同时背离，AI 判定为“高潮末端（一致性过强）”。

3. 完善“异动归因”逻辑
痛点： 盘中脉冲不知道是哪种战法的信号。
完善方案：【战法标签化分析仪】
当监控到股价异动（涨幅>3%，放量）时，系统进行“身份溯源”：
溯源 A（二波）： 该股是否是过去 30 天内的总龙头？回撤是否在 30%-50% 之间？若是 -> 标记为 [二波预警]。
溯源 B（低吸）： 该股是否为动态中军池成员？当前是否触及 20 日均线且缩量？若是 -> 标记为 [中军回踩]。
溯源 C（共振）： 此时大盘指数是否放量上涨？该板块是否有 3 只以上个股同时脉冲？若是 -> 标记为 [板块共振]。
溯源 D（抱团）： 市场成交额是否萎缩？大盘是否阴跌？该股是否在高位横盘不跌？若是 -> 标记为 [避险抱团]。
AI 推送示例：
“检测到 赛力斯 异动（+3.5%），归因：该股为核心中军，回撤至20日线后缩量止跌。符合 [低吸战法]。建议：关注分时均线支撑。”

4. 完善复盘的“神韵”（龙虎榜与席位分析）
痛点： 无法识别资金的“性格”。
完善方案：【席位画像库 + 资金审美分析】
建立游资字典：
格局派（A类）： 如“六一中路”、“上海超短”。特征：大单锁仓，喜欢格局，溢价高。
砸盘派（B类）： 如“拉萨天团”、“量化打压”。特征：散户多，第二天必砸，溢价低。
对倒派（C类）： 频繁出现在买卖两侧，虚假繁荣。
AI 深度解析：
将今日龙虎榜数据传给 AI。
LLM 任务： “今日龙一席位出现‘六一中路’，且买入金额是卖出的5倍。这说明主力锁仓意愿极强，属于‘强共识’，明天高开概率大，可以溢价接力。”
神韵提取： 让 AI 评估“谁在带队”。如果全是拉萨席位，AI 提醒“散户市，慎入”。

最终架构：AI 决策引擎的“三层过滤器”
底层（数据层 - Python + AkShare）：
抓取实时行情、LHB、连板梯队。
输出：结构化 Json 数据。
中层（逻辑层 - 战法算法）：
计算情绪评分、中军相关性、异动归因。
输出：带有标签的异动列表（如：中信海直 - [高度龙/二波博弈]）。
顶层（决策层 - 大模型 LLM）：
输入： 盘后数据 + 政策新闻 + 盘中异动标签。
输出： 充满“神韵”的操作指令（如：“当前市场处于发酵期，中军已回踩到位，明日早盘重点看 XX 的弱转强，买入信号参考竞价量能...”）。

感知层 (Python + AkShare)
复盘	统计涨停数、连板梯队、龙虎榜数据
盘前	抓取新闻、公告、同花顺热搜词
竞价	监控 09:25 的撮合量、涨幅、金额比例
盘中	监控成交量突增、炸板、股价回撤
推送	执行 Bark 推送接口

决策层 (LLM / GPT-4 / DeepSeek)
解析 市场灵魂股，判断赚钱/亏钱效应，定性 情绪周期
分析 热点级别，筛选 最具爆发潜力的板块和个股
验证 是否符合复盘时的“超预期”设定，下达买入指令
归因 异动原因，提醒是否属于“骗线”或“抱团切换”
润色 提醒文案，加入风险提示词


我要的功能为：
1、盘后复盘：统计今日连板梯队，胜率复盘，涨跌停数据，让ai分析市场情绪，龙虎榜解析，结合五大核心战法给出下个交易日操作建议以及个股买入标的。
需要给出下个交易日详细的买入操作建议，如开盘要求、竞价量能、买入条件、卖出条件、止盈止损条件等。

LLM 介入点： 将 AkShare 抓取的涨跌停数据、连板梯队、龙虎榜席位、成交额前20名个股，以 Text 形式喂给 LLM。
LLM 任务：
归纳逻辑： “今天涨停的 40 家公司中，有 25 家属于‘低空经济’，且呈现由高位向低位扩散的特征。”
定性周期： “最高标 7 连板，但中位股出现大面积掉队，市场处于‘高潮末端-退潮初期’。”
战法匹配： “明日不再适合打板接力，应转向‘抱团战法’，观察核心老龙头的低吸机会。”

如下示例：
场景 1：连板高位晋级龙头 (如 2 连板及以上)

- 开盘要求：高开 +3.0% ~ +6.0%（开太高容易被砸，开太低缺乏气势）。
- 竞价量能：09:25 竞价成交金额必须达到昨日全天成交额的 10% 以上（证明有大资金在竞价抢筹）。
- 买入条件：开盘 1 分钟内快速放量突破 09:25 竞价高点 ➔ 顺势半路扫板切入。

场景 2：一字板炸开重封或烂板 (分歧转一致)

- 策略类型：🔥 弱转强接力
- 开盘要求：超预期高开 +2.0% ~ +4.5%（昨日分歧严重，今日居然能高开就是“超预期”）。
- 竞价量能：09:25 竞价成交金额必须达全天 8% 以上。
- 买入条件：09:25 竞价直接挂单买入；或者开盘快速回踩不破均线、反抽放量瞬间切入。

场景 3：分歧首板 / 换手首板

- 策略类型：⚖️ 1 进 2 分歧承接
- 开盘要求：平开或轻微低开 -1.5% ~ +1.0%。
- 竞价量能：09:25 竞价成交金额必须达全天 5% 以上。
- 买入条件：低开/平开后，开盘 10 分钟内放量翻红并站上分时均线 ➔ 半路/低吸跟进

4. 盘中异动：捕捉“资金足迹”
实时监控全市场标的（每15秒轮询一次 stock_zh_a_spot_em）。

5. 卖出提醒：守护盈利
盘中实时监控持仓个股，结合以下条件给出卖出提醒：
情绪到顶预警：全市场连板家数超过极值（如连板高度达到8板以上），提示“风险极高，减仓”。
破位止损/止盈：跌破分时均价线且30分钟不收回，或者跌破关键支撑位（5日线）。
断板必卖：短线龙头一旦不封板，AI发出强制离场信号。
